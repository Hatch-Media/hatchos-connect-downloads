# HatchOS Connect

Mac installer downloads for the HatchOS Connect private pilot. This repository contains app packages, checksums and the Terminal downloader. It contains no R2 credentials, user sessions or private project media.

Requires macOS 13 or newer, on Apple Silicon or Intel. Download the latest versioned ZIP from [Releases](https://github.com/Hatch-Media/hatchos-connect-downloads/releases), unzip, and run the included `Install HatchOS Connect.command` with `bash` in Terminal. Sign in through HatchOS with Google, then add your test R2 connection in Settings.

This pilot is ad-hoc signed and is not Apple notarized. macOS may require first-launch approval in Privacy & Security. The installer preserves the previous app and does not bypass Gatekeeper or modify Keychain permissions.

Dropbox remains the production workflow while the private R2 pilot is tested. Test uploads do not change live task statuses.
